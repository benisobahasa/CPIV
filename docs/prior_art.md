# Prior-art review protocol

Purpose: establish what is genuinely new before making novelty claims. This file is a
protocol and log; add findings as you complete each search. No claims are made here.

## Decision rule
Claim "novel" only for specific, verified differences (for example multi-cause attribution
on a pair with controlled-intervention ground truth and faithfulness testing), never for the
whole field.
