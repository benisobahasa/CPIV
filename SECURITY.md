# Security and misuse policy

## Reporting a vulnerability
Open a GitHub security advisory on this repository (Security tab > Report a vulnerability),
or an issue labelled `security` if advisories are unavailable. Do not post exploits publicly
before maintainers can respond.

## Model files
`.joblib` models are Python pickles. Only load model files you trust.

## Misuse concerns
CPIV is dual-use research software. Report concerns about misuse (for example attempts to
use the evidence to evade detection) with the `ethics` label. See [ETHICS.md](ETHICS.md).
